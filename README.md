## 💻 Ejercicios Destacados

### 1. Estadísticas de la Materia (API) 📊
Un programa interactivo y robusto que gestiona las notas de una sección de alumnos para un número `n` de parciales fijados al inicio.
* **Lógica clave:** Control de ciclos anidados (`while` + `for`), reinicio estratégico de acumuladores por cada estudiante, manejo de strings para almacenar nombres con `strcpy()`, y algoritmos de búsqueda para hallar la nota máxima y mínima sin errores de inicialización.

### 2. Estadísticas del Semestre 🏫
Cálculo automatizado de promedios, aprobados y reprobados por materia del primer semestre de Computación, con control de daños para evitar divisiones entre cero (`total > 0`) y manejo de menús interactivos con `switch`.

### 3. Conversor de Unidades 📏
Un pequeño script que convierte medidas de metros a centímetros y milímetros.
